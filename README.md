Как пользоваться
Cookie — вставьте строку Cookie из браузера (как раньше), нажмите «Применить cookie».

Проверить сессию — если в логе {"d":""}, это нормально: сессия жива, но Russiahsearch без фильтров пуст.

Автоподбор эндпоинта — нажмите эту кнопку. Программа по очереди дёрнет все 7 эндпоинтов и в логе покажет, какой вернул данные:

text
Пробую: Russiahsearch (фильтры) → пустой 'd'
Пробую: bindallproduct (все авто) → УСПЕХ: 1234 авто
Рабочий эндпоинт: bindallproduct (все авто) (1234 авто)
Найденный эндпоинт автоматически подставится в выпадающий список и в поле URL.

Для Makersearch / ByID — впишите MID (код марки) или ID авто в поле «MID / ID».

Начать парсинг — запустит скачивание с выбранным эндпоинтом.

Если ни один эндпоинт не вернёт данные — пришлите лог автоподбора, и я подскажу, какой параметр ещё нужен (например, shop для Bodysearch или другой формат MID).
